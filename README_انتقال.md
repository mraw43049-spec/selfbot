# انتقال ربات به Railway جدید (بدون ریست شدن کاربرها)

## فایل‌ها (فقط این دو تا رو توی ریپو جایگزین/اضافه کن)
- `dbtransfer.py` (جدید) — دستورهای /backup و /restore
- `main.py` — فقط ۲ خط اضافه شده

## ترتیب کار
1. قبل از هر کاری توی Railway قدیمی، سرویس ربات ← Variables رو ببین: اگه `DATABASE_URL` هست، ادامه بده. اگه نیست، دیپلوی نکن و خبر بده (دیتا با دیپلوی پاک می‌شه).
2. این دو فایل رو توی گیت‌هاب بذار تا ربات قدیمی آپدیت بشه.
3. توی پی‌وی ربات با اکانت مالک بنویس `/backup`. فایل `.json.gz` میاد. همون‌جا بمونه.
4. بلافاصله ربات قدیمی رو خاموش کن (Remove deployment).
5. توی Railway جدید: پروژه از گیت‌هاب + Postgres جدید + همهٔ Variables (BOT_TOKEN و SELF_KEY عین قبلی). دیپلوی کن.
6. توی پی‌وی ربات جدید بنویس `/restore`، فایل بکاپ رو بفرست، «بله، جایگزین کن» رو بزن.
7. توی Railway جدید یک بار Redeploy کن.
8. فایل بکاپ رو از چت پاک کن (سشن‌های کاربرها داخلشه).
