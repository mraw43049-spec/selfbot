پروژه‌ی مستقل سلف
1) توی BotFather یه ربات جدید بساز و توکنش رو بردار.
2) یه ریپوی جدید توی GitHub بساز و همه‌ی فایل‌های این پوشه رو (با Upload files) بریز توش.
3) توی Railway یه پروژه‌ی جدید از اون ریپو بساز (سرور جدا).
4) توی Variables بذار: BOT_TOKEN, ADMIN_IDS, SELF_API_ID, SELF_API_HASH, SELF_KEY
   (برای ماندگاری اطلاعات: یه Postgres توی همون پروژه اضافه کن؛ DATABASE_URL خودش میاد)
5) Start Command: python main.py  (Procfile هم هست)
