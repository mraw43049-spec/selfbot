پروژه مستقل سلف ساز - نسخه منو و الماس

راه‌اندازی Railway:
1) فایل‌های ZIP را در ریپوی GitHub آپلود کنید.
2) در Railway از ریپو Deploy کنید و Start Command را `python main.py` بگذارید.
3) متغیرهای BOT_TOKEN، ADMIN_IDS، SELF_API_ID، SELF_API_HASH و SELF_KEY را تنظیم کنید.
4) برای ماندگاری اطلاعات در Railway یک PostgreSQL اضافه کنید تا DATABASE_URL ساخته شود.
5) ربات باید در هر دو کانال @selfsaz_iran و @fox_frenzy ادمین باشد تا عضویت کاربران را بررسی کند.
6) برای ارسال رسیدها به مدیرها، ADMIN_IDS را با آیدی عددی مدیرها تنظیم کنید. همچنین @escotch باید امکان دریافت پیام از ربات را داشته باشد؛ اگر دریافت پیام مستقیم ممکن نبود، رسید به مدیرهای ADMIN_IDS ارسال می‌شود.

امکانات افزوده‌شده: عضویت اجباری، منوی اصلی، ساخت سلف، خرید الماس و ارسال رسید برای مدیران، کیف پول، لینک دعوت، انتقال الماس و شارژ ساعتی.

قیمت‌ها: ۱ ماه = ۱۰۰۰ الماس / ۷۵٬۰۰۰ تومان؛ ۲ ماه = ۱۸۰۰ الماس / ۱۲۰٬۰۰۰ تومان.

نکته مهم: هرگز کد ورود تلگرام یا سشن را در اختیار افراد دیگر قرار ندهید. قبل از انتشار، روی یک ربات آزمایشی و دیتابیس پشتیبان تست کنید.
