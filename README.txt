پروژه‌ی مستقل سلف
1) توی BotFather یه ربات جدید بساز و توکنش رو بردار.
2) همه‌ی فایل‌های این پوشه را در GitHub آپلود کن.
3) در Railway از روی ریپو Deploy کن.
4) Variables: BOT_TOKEN, ADMIN_IDS, SELF_API_ID, SELF_API_HASH, SELF_KEY
   فقط شناسه 7433300089 مدیر اصلی کد است؛ ADMIN_IDS در main.py عمداً نادیده گرفته می‌شود.
5) Start Command: python main.py

امکانات تکمیلی پنل:
- فونت‌های یونیکد (ساده، بولد، ایتالیک، مونو) برای پیام‌های متنی بعدی
- ترجمه پیام ریپلای‌شده به فارسی با دستور .ترجمه (نیازمند اینترنت Railway)
- .تگ اعضا منشن محدود حداکثر ۱۰ عضو برای جلوگیری از اسپم
- تنظیمات وضعیت همیشه آنلاین و تایپینگ در پنل؛ این دو گزینه تضمین نمی‌کنند تلگرام وضعیت آنلاین/تایپینگ دائمی نشان دهد.

نکته: پیش از استفاده واقعی، در Railway لاگ‌ها را بررسی کن. قابلیت‌های مبتنی بر Telegram/Telethon ممکن است با محدودیت‌های حساب یا API روبه‌رو شوند.
